重建（Apple silicon Mac）：
1. 安装 Xcode 或 Apple Command Line Tools；21.0/21.1 本机构建采用 Xcode 27.2 的 macOS 27.2 SDK。
2. 保留官方 /Applications/SpektraLab.app 1.3.5 (20)，供脚本核对并复制未修改的编译资源。
3. 克隆官方源码并检出基线：
   git clone https://github.com/JamesQiu2005/SpektraLab.git SpektraLab-personal
   cd SpektraLab-personal
   git checkout spektralab-v1.3.5
4. 将本包 SpektraLab-personal-source 内全部内容复制覆盖到上述工作树，保留工作树的 .git。
5. 运行：
   python3 modern_UI/Spektrafilm/Tools/gen-project.py
   modern_UI/Spektrafilm/Tools/build-personal.sh
脚本会检查官方基线：除 engine/src/pipeline 下 engine.cpp、pipeline.cpp、pipeline.hpp 三个文件（21.0 的胶片缓存）外，引擎、着色器与资源必须与 1.3.5 一致；不自动安装应用、不关闭应用。
如果要改其他引擎文件或着色器，应按项目README使用完整Xcode正常构建。

macOS 自定义图标：
默认构建产物保持干净签名。新版 macOS 可能为 legacy ICNS 套银灰底板。
安装完成后可仅对景到应用使用 Apple NSWorkspace 自定义图标功能：
   swift modern_UI/Spektrafilm/Tools/set-personal-icon.swift /Applications/景到.app
使用包内 Personal.icns，无额外素材依赖，不修改系统设置、不清理全局图标缓存。
自定义操作会添加 FinderInfo 与 Icon\r 资源分支；普通 codesign --verify --deep 仍通过，--strict 会因这些 Finder 元数据报告 detritus。保留干净构建包用于严格签名核验；传递带自定义图标的本机应用时使用 Finder 或 ditto。
构建产物为 SpektraLab-personal-build/景到.app（应用标识仍为 com.mrfay.spektralab.personal）。
